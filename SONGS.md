# Как добавить песню в песенник

**Проще всего — через страницу `add-song.html`** (ditrihh.ru/add-song.html): вставляешь песню с аккордами над строками, она собирает готовый `songs.json`, который остаётся вставить на GitHub.

Поля `words` (слова), `music` (музыка) и `chordsBy` (кто подобрал аккорды) показываются в шапке песни.

Все песни лежат в файле `songs.json`. Каждая песня — это блок:

```json
{
  "id": "moya-pesnya",
  "title": "Название песни",
  "artist": "Исполнитель",
  "text": "{comment: Куплет}\n[Am]Строка текста с [Dm]аккордами\n[E]Вторая строка[Am]"
}
```

- `id` — короткое уникальное имя латиницей, без пробелов.
- `"exclusive": true` — твоя собственная аранжировка: получит значок «★ Эксклюзив» и встанет в начало списка на сайте и в приложении.

## Таб Guitar Pro

Положи файл в папку `tabs/` и добавь блок:

```json
{
  "id": "moya-aranzhirovka",
  "title": "Название",
  "artist": "Исполнитель",
  "tab": "tabs/moya-aranzhirovka.gp",
  "exclusive": true,
  "fingerstyle": true
}
```

`"aka": ["Duck Tales", "Утиные истории на гитаре"]` — другие названия и поисковые запросы: попадут в описание страницы для поисковиков и в поиск на сайте.

`"fingerstyle": true` — аранжировка в стиле фингерстайл: значок «Фингерстайл» и раздел табов `songs.html?type=tab&f=fs`.

Через минуту после сохранения songs.json GitHub сам создаст постоянную страницу песни: `ditrihh.ru/akkordy/<id>.html` (аккорды) или `ditrihh.ru/taby/<id>.html` (табы) — она же попадёт в sitemap.xml для поисковиков.
- Блоки разделяются запятыми, весь список в квадратных скобках `[ ... ]`.

## Формат текста

- Аккорд пишется в квадратных скобках **прямо перед слогом**, на котором его играть: `[Am]Ой, мороз, мороз, не мо[Dm]розь меня`.
- Новая строка — `\n`.
- Заголовок части: `{comment: Припев}`.
- Строка только из аккордов (проигрыш): `[Em] [C] [G] [D]`.
- Можно писать `H` вместо `B` (Hm = Bm), `#` и `b` для диезов и бемолей, `Am7`, `E7`, `Cmaj7`, `Asus4`, `Am/G`.

## Проще всего

Пришли текст с аккордами в чат в любом привычном виде (аккорды над строками), и он будет переведён в этот формат и добавлен.

Тексты песен защищены авторским правом. Добавляя чужие песни, учитывай это: безопаснее народные песни, свои песни и песни, на которые есть разрешение автора.
