# ditrihh — состояние проекта (для продолжения в новом чате)

Обновлено: 8 октября 2026.

## Что это
- **Сайт ditrihh.ru** (GitHub Pages из этого репозитория, ветка `main`, корень) и **Telegram Mini App** бота @ditrihh_bot — один код.
- Бренд: **ditrihh**, логотип с грифом гитары на первой «i» (`brand/`, генератор `brand/make-logo.py`, шрифт Russo One). Цвета: неоновые сине-фиолетовые (как на стримах), акцент оранжевый `#F0A830`.

## Файлы
- `index.html` — главная сайта: окно стрима (справа от плеера вместо чата — топ донатеров DonationAlerts: Месяц / Неделя / Последние, цель сбора, кнопка «Задонатить»; Twitch-плеер без звука во время эфира; офлайн — отсчёт до 00:00 МСК и «Запись последнего стрима» с Twitch), школа, эксклюзивные табы, донат (dalink.to/ditrihh). Если открыта из Telegram — сразу переходит в `app.html`.
- `songs.html` — каталог «Эксклюзивные табы и аккорды от ditrihh» (поиск, фильтры, значок ★ Эксклюзив).
- `song.html?id=…` — отдельная страница песни на сайте: аккорды (тон, размер, автопрокрутка, схемы, звук по кнопке) или таб-плеер alphaTab.
- `site.css` — общие стили сайта.
- `school/index.html` (адрес ditrihh.ru/school/; `app.html` — переадресация для старых ссылок и Telegram) — приложение: путь обучения (ноты/аккорды/интервалы), тренажёр слуха, рейтинговая битва, лиги недели, профиль, песенник, таб-плеер. В браузере шире 900px — веб-раскладка с верхним меню.
- `songs.json` — песни (формат в `SONGS.md`; `"exclusive": true` — своя аранжировка).
- `server/index.js` — функция Yandex Cloud `fretboard-lb` (загружается вручную ZIP-архивом): рейтинг недели, лиги, общий прогресс, привязка Telegram к сайту (link/claim/token), Twitch API (последняя запись и статус эфира).
  - Переменные окружения: `BOT_TOKEN`, `BUCKET`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`.
  - Прогресс хранится по аккаунту `progress/tg_<id>.json`; заготовка под будущие `vk_<id>` / `ya_<id>` через `alias/tg_<id>.json`.

## Сделано недавно
- Домен ditrihh.ru подключён (файл `CNAME`, DNS у reg.ru → GitHub).
- Привязка Telegram на сайте (плашка в меню и кнопка в профиле), синхронизация прогресса в обе стороны.
- Таб-плеер: цветные/обычные цифры, строка/перенос, масштаб, пробел — играть/пауза, контрастные линии.
- Схемы аккордов: прямоугольное баррэ, номер лада справа от него, крестики в цвет схемы, звук только по кнопке и медленнее.

## Страницы песен
`scripts/build-songs.mjs` делает akkordy/<id>.html и taby/<id>.html + sitemap.xml. GitHub Actions (`.github/workflows/build-songs.yml`) запускает его при каждом изменении songs.json — руками ничего делать не нужно.

**Видео с игрой на странице песни:** поле `"video"` в songs.json — ссылка YouTube (видео/Shorts) или VK Видео/клип; встаёт справа от названия (на телефоне — под ним). Shorts и клипы VK — вертикальной карточкой; `"videoV": true/false` — задать формат вручную. После правки songs.json страницы песен пересобираются сами (GitHub Actions).
